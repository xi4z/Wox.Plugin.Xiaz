## v0.7.0 — OpenCode Go usage

This release adds OpenCode Go to the quota list.

### What's new

- The new `opencode` command (also part of the combined `quota` list) reads the Go allowance from `https://opencode.ai/zen/go/v1/usage`
- The `rolling`, `weekly` and `monthly` windows render as separate progress bars with reset countdowns and a `rate limited` marker for exhausted windows
- The API key is read from an environment variable at refresh time — default `OPENCODE_GO_API_KEY`, renameable in the plugin settings. Nothing is written to disk
- Missing key, invalid/revoked key, key without a Go subscription, throttled queries and partial payloads get their own message instead of invented numbers
- English and Chinese strings for every new row; plugin version bumped to 0.7.0

### Install

Download `Wox.Plugin.Xiaz-0.7.0.wox` from the assets below, or build from source:

```bash
pnpm install && pnpm run build
```

### Setup for OpenCode Go

```bash
# macOS / Linux
export OPENCODE_GO_API_KEY="sk-..."          # key from the OpenCode Console (Go plan)

# Windows (PowerShell, current user)
setx OPENCODE_GO_API_KEY "sk-..."
```

Restart Wox afterwards, then type `quota` or `opencode` in the launcher.
